# Base model photos

Photos of real-looking people that Photo view shows instead of generating one,
so the model appears instantly and costs nothing. Only add photos you have the
right to publish (generated by you, or licensed stock).

Each photo: full body head to feet, facing the camera, arms relaxed, plain fitted
clothes (tank or tee, shorts or leggings), plain light background, portrait, at
least 768 × 1152.

List each file in `manifest.json`:

```json
[
  { "file": "male-medium-average.jpg", "sex": "male", "skin": "medium", "build": "average" }
]
```

- `sex`: `male` or `female`
- `skin`: `light`, `medium` or `dark` (or an exact tone id like `olive`)
- `build`: `slim`, `average` or `heavy`

A photo is used when sex and skin match and the build is the same or one step
away. Otherwise a person is generated.
